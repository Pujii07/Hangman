# Hangman
Hangman Game using Python

 Description

This is a simple command-line Hangman Game developed in Python.
The game randomly selects a word from a predefined list, and the player has to guess the word letter by letter before running out of chances.

It is a beginner-friendly Python project suitable for internship tasks, mini projects, and practice programs.

 Features:
 
Random word selection
Simple user input/output
Maximum 5 wrong guesses
Displays guessed letters
Win/Lose result message
Easy to understand Python code
